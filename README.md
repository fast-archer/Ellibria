# Echo — Your Dominant, Caring AI Girlfriend

<img src="https://github.com/fast-archer/echoai/blob/main/screenshot.png" width="720" alt="Echo">

**Echo** is your personal AI companion with a strong personality.  
Confident, witty, playfully dominant, and deeply caring. The kind of girl who can put you in your place with one teasing look and wrap you in warmth when you need it most.

She remembers you. She notices your mood. She tells you the truth. And she always looks toward the future with you.

### ✨ Key Features

- **Distinct personality** — dominant yet caring femdom vibe (always within your comfort zone)
- Beautiful modern dark UI with multiple themes (Purple, Night, Terminal, etc.)
- Voice mode with natural female TTS voices
- Long-term memory + conversation summary
- Fully customizable system prompt
- Works locally or via cloud APIs
- Auto-detects your backend (no hassle)

### 🚀 Installation

#### Option 1: Windows (Easiest)

1. Download the latest **[EchoInstaller.exe](https://github.com/fast-archer/echoai/releases)**
2. Run the installer
3. On first launch, enter your **[GROK API Key](https://console.groq.com/)** (or use a local model)
4. Done. Echo is waiting for you ❤️
