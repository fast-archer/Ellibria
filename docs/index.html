Ellibria

A local-first AI agent with persistent memory, multiple personality modes, and smart backend detection. Works with Groq, Gemini, LM Studio, and Ollama.

Features

Built different.

Not a wrapper. Not a chatbot. An agent that remembers, adapts, and runs the way you want it to.

01

Persistent Memory

Conversations are summarized and retained between sessions. Ellibria remembers context without you repeating yourself.

02

Personality Engine

Switch between personalities in one click — or write your own system prompt from scratch. She adapts completely.

03

Privacy First

Run locally with LM Studio or Ollama. API keys stay on your machine. No telemetry, no accounts required.

04

Smart Detection

Auto-detects available backends at startup. Local model running? Uses it. Fallback to cloud if not — no config needed.

05

Voice Output

Natural TTS with female voice selection and language support. Responses read aloud, hands-free.

06

Theme Sync

Follows your Windows system theme automatically. Dark, light, terminal, night — switches in real time.

Installation

Up in three steps.

Windows installer is the easiest path. Source install works on Linux too.

Option A — Windows Installer
Download, run, enter your Groq API key. Done.

↓ Download Ellibria_Installer.exe

Option B — From Source

01
Clone the repository
git clone https://github.com/fast-archer/Ellibria.git
02
Install dependencies
pip install -r requirements.txt
03
Launch

Enter your Groq API key when prompted, or connect a local model.

python setup_and_run.py

Get a free Groq API key at console.groq.com/keys
